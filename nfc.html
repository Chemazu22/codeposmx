Preguntas frecuentes

¿Tienes una idea diferente? Cuéntanos qué quieres lograr.

¿Qué es un tarjetero NFC?

Es una tarjeta o soporte con un chip NFC que permite que un teléfono compatible detecte un enlace al acercarlo. La persona puede necesitar tocar la notificación para abrirlo.

¿También puedo usar un código QR?

Sí. Podemos incluir NFC, QR o ambos. El QR ofrece una alternativa para personas cuyos teléfonos no tengan NFC disponible.

¿Necesito instalar una aplicación?

Normalmente no se necesita una aplicación especial para leer un enlace NFC o QR. El comportamiento puede variar según el dispositivo.

¿Qué información puede abrir?

Puede dirigir a una tarjeta de contacto, redes sociales, menú digital, página de reseñas u otro enlace acordado.

¿Puedo personalizarlo con mi marca?

Podemos revisar las opciones de personalización disponibles según el tipo de tarjetero y la cantidad que necesites.

¿Cuánto cuesta y cuánto tarda?

El precio y el tiempo dependen del tipo de producto, personalización y cantidad. Escríbenos para preparar una cotización.
